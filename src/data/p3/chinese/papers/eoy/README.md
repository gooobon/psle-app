## Schema notes

Each file exports a default array of `SingleQuestion | SetQuestion` objects.
- `SingleQuestion` – standalone items (BianZi, PinYin, CiYu, JuZi standalone)
- `SetQuestion` – passage / set items (TianKong, PeiDui, KanTu, ZuJu, YueReadMCQ, YueReadOpen)

Optional fields in use:
- `needsParentVerify?: boolean` – flagged where answer-key conflict was noted
- `wordBank?: string[]` – word bank on SetQuestion

Difficulty ratings: `"foundation"` | `"core"` | `"stretch"`
