나는 "Genius Project"라는 싱가포르 초등 시험 대비 웹앱을 만들고 있고, 이전 채팅에서 하던 P3 고급화문(Higher Chinese, 华文) WA1 구축 작업을 이 새 채팅창에서 그대로 이어서 진행할 거야.

[가장 먼저 할 일 — 0단계]
이 메시지에 아래 파일들을 첨부했어. 너의 /mnt/user-data/uploads/ 디렉토리에서 존재를 확인하고, "ZH_WA1_HANDOFF_v3.md"(이관 문서)를 전체 읽어. 이 문서가 유일한 기준(single source of truth)이야. 문서의 [1. 첨부 파일 검증] 절차를 그대로 수행해 결과를 보고해. 하나라도 없으면 작업을 시작하지 말고 재첨부를 요청해.

[첨부 파일 목록 — 전부 텍스트(이미지 0개), 문제집 PDF만 이미지]
필수(작업 핵심):
1. ZH_WA1_HANDOFF_v3.md — 이관 문서 (진행상황·규칙·결정사항·스키마·다음작업 전부 담김). 이거 먼저 읽어.
2. seed_zh_all.json — 확정 통합 시드 (16개교). 가장 중요한 자산. 절대 처음부터 다시 만들지 말고 여기에 이어붙여.
3. zh_wa1_schema.ts — 데이터 스키마 (SentenceOrder·SentenceCraft 포함)
4. zh_wa1_validate.js — 검증 모듈 (SentenceOrder·SentenceCraft·answerKey 교차검증 포함)
5. zh_wa1_selftest.js — 자가테스트 (node로 돌리면 27 pass / 0 fail 나와야 함)
6. build_seed_all.js — 시드 통합·검증 빌더
7. check_seed.js — 단일 시드 검증
8. (내가 준비한) P3 Higher Chinese 문제집 PDF (~50페이지) — 이번 작업의 첫 분석 대상

[검증 후 절차 — HANDOFF 문서 지침대로]
0단계(파일 검증: selftest 27/0, seeds 16 확인) 결과 보고 → HANDOFF의 [2 컨텍스트][3 진행상황]을 읽고 이해한 현재 상태를 5줄 이내로 요약해 나에게 확인받기 → 그다음 [7-A 다음 작업]으로 진행.

[이번 세션에서 할 일 — 문제집 PDF 활용]
실제 기출만으로는 문제 풀이 부족해서, 시중에 나와있는 P3 Higher Chinese 문제집 PDF를 실제 기출과 함께 문제 풀(pool)에 넣고 60문제 세트를 생성할 계획이야. 그래서 새 창의 첫 임무는 HANDOFF [7-A]대로:
1. 첨부한 문제집 PDF를 페이지별로 분석해서 섹션·문항 유형을 전부 나열하고,
2. 우리가 지금까지 만든 문제유형 구조(스키마 ZhSectionType 15종)와 정확히 맞는지 표로 비교하고,
3. 이 문제집 문항을 우리 구조(raw seed 규약·lesson 1~4·해설 4요소·answerKey/answer0)에 맞게 어떻게 수정·변형·개선해야 하는지 철저하고 완벽하게 검토한 다음,
4. 이 문제집 PDF를 어떻게 활용할지(시드 직접 추출 / 60세트 생성기 few-shot 예시 pool / 병목 duoyinzi·liangci 보강 등) 보고해.
5. 위 1~4를 보고하고 내 확인을 받은 뒤에 실제 추출/생성으로 진행해. 추측 금지, 실제 PDF 확인 후 판단.

[핵심 규칙 (자세한 건 HANDOFF에)]
- 학생 실제 시험 성적 향상이 목표. 문제 유형·구조를 항상 비판적으로 재점검하고 개선점 선제 보고. MOE P3 HCL WA1 커리큘럼(1~4과) 적합성 상시 확인(WA2급 어휘 오염 차단). 해설은 "왜 정답+왜 각 오답 틀림+함정유형+기억포인트"까지.
- 모든 보고는 한국어. 추측 금지. 코드는 완전 파일 교체본 또는 원자적 node 패치로 /mnt/user-data/outputs/에 전달. 코드에 이모지·비ASCII 금지(문항 중문·병음·해설은 예외).
- 다른 창에서도 seed_zh_all.json을 갱신 중일 수 있으니, 새 시드 추가 전 최신 업로드본을 base로 삼고 기존 시드 보존 확인 후 이어붙여.
- 너의 이미지 뷰어가 일부 스캔 PDF 페이지를 렌더 못 할 수 있어. 그럴 땐 육안 확정 말고 나한테 해당 페이지 스크린샷을 요청해. 정답키와 문맥이 충돌하면 문맥상 명백한 정답을 채택하고 불일치를 시드에 기록해.
- 기존 기출 PDF(P3_Chinese_WA1.pdf 113p, P3_High_Chinese_WA1.pdf 66p)는 이미 시드에 추출됐으니 첨부하지 않았어(이미지 한도 때문). 그 내용은 seed_zh_all.json에 있어.
