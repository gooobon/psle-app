## Gaps

1. **Milestone alert does not run while WhatsApp is off.** `notifyEvent` returns immediately unless `WHATSAPP_ENABLED=true` (`src/lib/notify/eventAlerts.mjs`, `masterOn`). With email and WhatsApp left off, as this run required, `event_alert_log` has no milestone row and there is no dry-run of the final score. The weekly report dry-run does carry `7/40 (18%)`. Proposed issue: let the milestone render a dry-run email the same way the weekly report does when WhatsApp is off.
2. **The past-paper practice history line still says Nanyang.** The exam header uses `plan.paperLabel` and showed Anglo-Chinese School (Junior). When that mock is finished, `handleSessionDone` in `src/app/ClaudeApp.js` still stores `school: "Nanyang Primary"` and `examType: "WA1"` whenever `isMock` is true, and a past-paper mock passes `forceMock`, which sets `isMock`. The student "My Progress" row is `Mock: ${h.school} ${h.examType}`. That saved row was not opened in this run. Proposed fix: for `forceMock`, store `pastPlan.paperLabel` (the same value the header already shows) and keep "Nanyang Primary" only for the every-10th practice-set mock.
3. **A question printed as "(2 marks)" adds 1 to the score.** Parent marks on Tao Nan moved the score by 1 per item (`6/36` → `7/37` for one correct mark). The open questions on that card are labelled "(2 marks)". This matches the PR note that the unit stays one item = one point. Proposed issue if the printed marks should be the unit.
4. **No paper has an unreadable order key to click.** 45/45 order wordings parse. The parent-mark fallback for a bad key was not sat.
5. **Word-bank cloze is a row of word buttons, numbered with the passage numbers.** Tao Nan 21–24 are `(21)` plus buttons `A. down`, `B. in`, and so on. They are not empty text boxes. Grading stores the word.
6. **The Saturday credit stays pending until that day's homework is finished.** No homework was assigned, so the parent unpaid balance stays 0 and both wallets say the 6 credits (S$3.00) are pending. The credit row's status is `pending`. That is the homework gate, and it did not confirm the credit during the day.
